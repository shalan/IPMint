## 🚀 Features

- **Easy IP Discovery:** Search and list IPs from the central repository.
- **Robust Dependency Management:** Automatic SAT-based dependency resolution, circular dependency prevention.
- **Reproducible Installs:** Lock file support for consistent environments.
- **IP Packaging:** Validate and package your own IPs for distribution.
- **Activity Logging:** Local log of all actions for audit and troubleshooting.
- **Cross-Platform:** Works on Linux, macOS, and Windows (WSL2).
- **No Authentication Required:** Open access for public IPs.
